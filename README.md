# vidnotes

Видео → markdown: расшифровка речи + скриншоты ключевых мест. Речь распознаётся локально, а какие моменты считать ключевыми — решает Claude по тексту расшифровки.

Пользоваться можно окном или командной строкой — считает одно и то же.

## Скачать и запустить

Готовые сборки лежат в [релизах](https://github.com/kulihaEvgn/video-transcriptor/releases) — качать ничего, кроме архива, не нужно, python и ffmpeg уже внутри.

1. Скачай архив под свою систему и распакуй: `vidnotes-windows.zip` или `vidnotes-macos.zip`.
2. Запусти `vidnotes` из папки (Windows) или `vidnotes.app` (macOS).
3. Первый запуск система поругается, что приложение не от известного разработчика — подписи у нас нет. На Windows: «Подробнее» → «Выполнить в любом случае». На маке: правый клик по `vidnotes.app` → «Открыть» → «Открыть» в диалоге. Дальше запускается обычным двойным щелчком.

**Что нужно кроме этого:** установленный [Claude Code](https://claude.com/claude-code) — приложение зовёт его, чтобы выбрать ключевые моменты. Проверить просто: открой терминал (на Windows — PowerShell) и набери `claude --version`. Если команда не находится — сначала поставь его, иначе расшифровка сделается, а моменты выбрать будет нечем.

При первом запуске нажми «Скачать модель» — сколько качать, написано на самой кнопке (для модели по умолчанию около полутора гигабайт). Это разово.

## Окно

```
vidnotes-gui
```

Три шага сверху вниз:

1. **Скачать модель** — кнопка активна, только если модели ещё нет, и её вес написан прямо на кнопке. Качается один раз, потом лежит в кэше, кнопка гаснет, а рядом видно, сколько места модель занимает.
2. **Выбрать видео…** — под кнопкой перечислены форматы, которые читаем: mp4, mov, mkv, webm, avi, m4v, mpg, mpeg, wmv, flv. Рядом язык речи и сколько моментов взять.
3. **Начать** — идёт расшифровка, в поле снизу видно, что распознаётся прямо сейчас. По окончании оживает **Сохранить результат…**: выбираешь папку, туда переезжает markdown и папка с кадрами, и она сразу открывается в проводнике.

Пока работа идёт, всё считается во временной папке — если закрыть окно на середине, ничего никуда не запишется.

## Командная строка

```
vidnotes созвон.mp4              # язык определяется сам, 12 моментов
vidnotes созвон.mp4 ru 20        # язык и сколько моментов взять
vidnotes демо.mov en 6 -o ~/Desktop   # результат в другую папку
```

Реализации две, команда и результат у них одинаковые:

| | `vidnotes` (bash) | `vidnotes.py` (python) |
| --- | --- | --- |
| для кого | macOS | Windows, Linux |
| распознавание | whisper.cpp на Metal | faster-whisper на CPU |
| скорость | ~11× быстрее записи | зависит от процессора, обычно 2–5× |
| ставится | brew | uv / pipx |

На маке бери bash-версию: она использует видеокарту и потому в разы быстрее.

## Установка на macOS

```bash
brew install ffmpeg whisper-cpp jq
mkdir -p ~/.cache/whisper-cpp
curl -L -o ~/.cache/whisper-cpp/ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
ln -sf "$PWD/vidnotes" ~/.local/bin/vidnotes
```

## Установка на Windows и Linux

```bash
uv tool install git+https://github.com/kulihaEvgn/video-transcriptor
# или, если привычнее pipx:
pipx install git+https://github.com/kulihaEvgn/video-transcriptor
```

Ставятся сразу две команды: `vidnotes-gui` — окно, `vidnotes` — командная строка.

Всё нужное приезжает пакетами: ffmpeg отдельно ставить не надо, он уже внутри библиотеки `av`, которой читается видео. Модель качается сама при первом запуске (около полутора гигабайт), дальше берётся из кэша.

Обеим версиям нужен `claude` — Claude Code CLI. Он работает по подписке, отдельный API-ключ не требуется.

## Аргументы

| Позиция | Что                | По умолчанию | Примеры                     |
| ------- | ------------------ | ------------ | --------------------------- |
| 1       | файл видео         | обязателен   | `созвон.mp4`, `демо.mov`    |
| 2       | язык речи          | `auto`       | `ru`, `en`, `de`            |
| 3       | сколько моментов   | `12`         | `6` для демо, `25` для часа |

Язык лучше указывать явно: на `auto` whisper иногда путает язык на первых секундах и дальше расшифровывает неверно.

### Переменные окружения

`WHISPER_MODEL` — другая модель распознавания. В bash-версии это путь к файлу `.bin`, в python-версии — имя модели, которое скачается само:

```bash
WHISPER_MODEL=small vidnotes созвон.mp4 ru          # python: быстрее и хуже
WHISPER_MODEL=~/.cache/whisper-cpp/ggml-base.bin vidnotes созвон.mp4 ru   # bash
```

`VIDNOTES_AGENT` — чем выбирать моменты. По умолчанию `claude -p`. Любая другая команда получит на вход промпт и транскрипт одним куском, а вернуть должна строки вида `HH:MM:SS | подпись` — всё остальное в её ответе игнорируется:

```bash
VIDNOTES_AGENT="ollama run llama3" vidnotes созвон.mp4 ru
```

## Что получается

Рядом с видео:

```
созвон.mp4
созвон_notes.md          ← это и читаем
созвон_notes/
  transcript.srt         реплики с таймкодами
  transcript.txt         сплошной текст
  moments.txt            то, что выбрал агент: таймкод | подпись
  shots/01_00-12-30.jpg  кадры: номер по порядку и таймкод момента
  …
  agent.txt              сырой ответ агента
  whisper.log            лог расшифровки (только bash-версия)
```

`созвон_notes.md` — заголовок на каждый момент, под ним кадр, в конце полный транскрипт. Картинки лежат по относительным путям, так что папку `_notes` надо таскать вместе с `.md`.

## Как это работает

1. видео скармливается распознавалке речи, получаются реплики с таймкодами;
2. транскрипт уходит агенту, тот возвращает моменты — где что-то решили, показали или сменили тему;
3. на каждом таймкоде вырезается кадр, всё склеивается в markdown.

## Сколько ждать и сколько стоит

Замер на M1 Pro: запись экрана 43 минуты, 2,5 ГБ, звук через видеосвязь. Обе версии считали одно и то же видео.

| Что                     | Сколько                                    |
| ----------------------- | ------------------------------------------ |
| весь прогон, bash       | 3 мин 55 с (в 11 раз быстрее записи)       |
| весь прогон, python     | 8 мин 20 с (в 5 раз быстрее записи)        |
| из них шаг с Claude     | 17 с                                       |
| токенов на вход         | 61 320 (16 330 из кэша)                    |
| токенов на выход        | 905                                        |
| стоимость шага с Claude | $0,48                                      |
| папка на выходе         | 12 МБ (30 кадров + транскрипт)             |

Первый запуск после установки на полминуты дольше — whisper компилирует Metal-шейдеры, дальше берёт их из кэша.

Про стоимость: сам транскрипт — это тысяч двадцать пять токенов, остальные тридцать шесть тысяч приходят из системного промпта Claude Code, который CLI отправляет при каждом вызове. То есть больше половины цены — накладные расходы обёртки, а не твои данные.

## Если что-то пошло не так

**`агент не вернул таймкоды`** — расшифровка при этом уже готова, посмотри `_notes/transcript.srt` и сырой ответ в `_notes/agent.txt`. Обычно значит, что записи почти без речи, либо `claude` не авторизован (проверь `claude -p "привет"`).

**Текст расшифрован не на том языке** — укажи язык вторым аргументом.

**Кадры пустые или чёрные** — момент попал на затемнение между сценами; выбери больше моментов, либо возьми таймкод из `moments.txt` и вырежи кадр руками:
`ffmpeg -ss 00:12:30 -i созвон.mp4 -frames:v 1 кадр.jpg`

**Python-версия расшифровывает очень долго** — это CPU без ускорителя. Возьми модель поменьше: `WHISPER_MODEL=small` или `WHISPER_MODEL=medium`.

## Чего скрипт не умеет

Не различает говорящих, не режет длинные записи на куски (транскрипт уходит агенту целиком — часа на три речи запаса хватает) и не выбрасывает похожие кадры.
