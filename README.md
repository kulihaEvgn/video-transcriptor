# vidnotes

Видео → markdown: расшифровка речи + скриншоты ключевых мест. Один bash-скрипт, всё считается локально, кроме выбора моментов — его делает Claude.

```
vidnotes созвон.mp4              # язык определяется сам, 12 моментов
vidnotes созвон.mp4 ru 20        # язык и сколько моментов взять
vidnotes демо.mov en 6
```

## Установка (разово)

```bash
brew install ffmpeg whisper-cpp jq
mkdir -p ~/.cache/whisper-cpp
curl -L -o ~/.cache/whisper-cpp/ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
ln -sf ~/code/projects/vidnotes/vidnotes ~/.local/bin/vidnotes
```

Нужен ещё `claude` (Claude Code CLI) — берётся из твоей подписки, API-ключ не требуется.

## Аргументы

| Позиция | Что                | По умолчанию | Примеры                     |
| ------- | ------------------ | ------------ | --------------------------- |
| 1       | файл видео         | обязателен   | `созвон.mp4`, `демо.mov`    |
| 2       | язык речи          | `auto`       | `ru`, `en`, `de`            |
| 3       | сколько моментов   | `12`         | `6` для демо, `25` для часа |

Язык лучше указывать явно: на `auto` whisper иногда путает язык на первых секундах и дальше расшифровывает неверно.

Переменная окружения `WHISPER_MODEL` подменяет модель:

```bash
WHISPER_MODEL=~/.cache/whisper-cpp/ggml-base.bin vidnotes созвон.mp4 ru
```

`base` — раза в четыре быстрее и заметно хуже на русском; имеет смысл, когда надо просто понять, о чём была запись.

## Что получается

Рядом с видео:

```
созвон.mp4
созвон_notes.md          ← это и читаем
созвон_notes/
  transcript.srt         реплики с таймкодами
  transcript.txt         сплошной текст
  moments.txt            то, что выбрал Claude: таймкод | подпись
  shots/01_00-12-30.jpg  кадры: номер по порядку и таймкод момента
  …
  whisper.log            лог расшифровки, нужен только при разборе проблем
```

`созвон_notes.md` — заголовок на каждый момент, под ним кадр, в конце полный транскрипт. Открывается в любом просмотрщике markdown; картинки лежат по относительным путям, так что папку `_notes` надо таскать вместе с `.md`.

## Как это работает

1. `ffmpeg` вытаскивает дорожку в моно 16 кГц;
2. `whisper-cli` (whisper.cpp на Metal) расшифровывает её в `.srt` и `.txt`;
3. `claude -p` читает `.srt` и возвращает список «таймкод | подпись» — моменты, где что-то решили, показали или сменили тему;
4. `ffmpeg` режет кадр на каждом таймкоде, всё склеивается в markdown.

## Сколько ждать и сколько стоит

Замер на реальном созвоне: запись экрана 43 минуты, 2,5 ГБ, звук через видеосвязь.

| Что                     | Сколько                                    |
| ----------------------- | ------------------------------------------ |
| весь прогон             | 3 мин 55 с (в 11 раз быстрее записи)       |
| из них шаг с Claude     | 17 с                                       |
| токенов на вход         | 61 320 (16 330 из кэша)                    |
| токенов на выход        | 905                                        |
| стоимость шага с Claude | $0,48                                      |
| папка на выходе         | 12 МБ (30 кадров + транскрипт)             |

Первый запуск после установки на полминуты дольше — whisper компилирует Metal-шейдеры, дальше берёт их из кэша.

Про стоимость: сам транскрипт — это тысяч двадцать пять токенов, остальные тридцать шесть тысяч приходят из системного промпта Claude Code, который CLI отправляет при каждом вызове. То есть больше половины цены — накладные расходы обёртки, а не твои данные. На прямом API те же данные обошлись бы примерно в десять центов, но тогда нужен API-ключ; сейчас всё идёт по подписке.

## Если что-то пошло не так

**`Claude не вернул таймкоды`** — расшифровка при этом уже готова, посмотри `_notes/transcript.srt`. Обычно значит, что запись почти без речи, либо `claude` не авторизован (проверь `claude -p "привет"`).

**`whisper не выдал транскрипт`** — смотри `_notes/whisper.log`. Чаще всего в файле нет звуковой дорожки.

**Текст расшифрован не на том языке** — укажи язык вторым аргументом.

**Кадры пустые или чёрные** — момент попал на затемнение между сценами; выбери больше моментов, либо возьми таймкод из `moments.txt` и вырежи кадр руками:
`ffmpeg -ss 00:12:30 -i созвон.mp4 -frames:v 1 кадр.jpg`

## Чего скрипт не умеет

Не различает говорящих, не режет длинные записи на куски (транскрипт уходит в Claude целиком — часа на три речи запаса хватает) и не выбрасывает похожие кадры.
