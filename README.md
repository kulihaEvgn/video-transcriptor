# vidnotes

Видео → markdown: расшифровка речи и скриншоты ключевых мест. Речь распознаётся локально, а какие моменты считать ключевыми — решает Claude по тексту расшифровки.

Ставится плагином в Claude Code — ничего собирать, подписывать и разрешать в системе не нужно.

## Установка

```
/plugin marketplace add kulihaEvgn/video-transcriptor
/plugin install vidnotes@vidnotes
```

Нужен ещё [uv](https://docs.astral.sh/uv/) — окружение с распознавалкой поднимается им на лету: `brew install uv` на маке, `winget install astral-sh.uv` на Windows. Это разово.

Модель (около 550 МБ) скачается при первом разборе видео, с вопросом. Дальше лежит на диске.

## Как пользоваться

Просто скажи Claude, чего хочешь:

```
сделай конспект записи ~/Downloads/созвон.mp4, там по-русски
что обсуждали на встрече? запись на рабочем столе
разбери ~/Movies/демо.mov, там по-английски
```

Claude расшифрует запись, сам выберет ключевые моменты по тексту, вырежет кадры и отдаст markdown: заголовок на каждый момент, под ним скриншот, в конце полный транскрипт.

Расшифровка идёт локально, наружу уходит только текст транскрипта — тому же Claude, который и так работает у тебя в терминале.

## Что получается

Рядом с видео:

```
созвон.mp4
созвон_notes.md          ← это и читаем
созвон_notes/
  transcript.srt         реплики с таймкодами
  transcript.txt         сплошной текст
  moments.txt            выбранные моменты: таймкод | подпись
  shots/01_00-12-30.jpg  кадры: номер по порядку и таймкод момента
  …
```

Картинки лежат по относительным путям, так что папку `_notes` надо носить вместе с `.md`.

## Сколько ждать

Замер на M1 Pro: запись экрана 43 минуты, 2,5 ГБ, звук через видеосвязь.

| Что | Сколько |
| --- | --- |
| расшифровка | 3 мин 25 с (в 12 раз быстрее записи) |
| нарезка кадров | меньше секунды |
| папка на выходе | 12 МБ на 30 кадров |

На маке считает видеокарта (Metal), на Windows и Linux — процессор, там будет в несколько раз дольше. Если ждать не хочется, возьми модель поменьше: `WHISPER_MODEL=small` или `medium` — быстрее и заметно хуже на русском.

## Без Claude Code

Плагин — не единственный способ, внутри обычный питоновский скрипт.

**Командная строка.** Тогда моменты выбирает не твой Claude, а отдельно запускаемый `claude -p`, и это стоит примерно полдоллара на часовую запись — из-за служебного промпта, который CLI шлёт при каждом вызове.

```bash
uv tool install git+https://github.com/kulihaEvgn/video-transcriptor
vidnotes созвон.mp4 ru          # число моментов посчитается от длительности
vidnotes демо.mov en 6 -o ~/Desktop
```

**Окно с кнопками:** `vidnotes-gui` — скачать модель, выбрать видео, сохранить результат. Готовых сборок нет: неподписанное приложение блокируют и Windows, и macOS, а отключать защиту ради этого неправильно.

### Переменные окружения

`WHISPER_MODEL` — какая модель. Имя (`small`, `medium`, `large-v3-turbo-q5_0`) или готовый путь к файлу `.bin`, если он у тебя уже есть.

`VIDNOTES_AGENT` — чем выбирать моменты там, где Claude Code не участвует: в командной строке и в окне. По умолчанию `claude -p`. Любая другая команда получит на вход промпт с транскриптом, а вернуть должна строки `HH:MM:SS | подпись`:

```bash
VIDNOTES_AGENT="ollama run llama3" vidnotes созвон.mp4 ru
```

## Если что-то пошло не так

**Текст расшифрован не на том языке** — назови язык явно, на `auto` whisper иногда ошибается на первых секундах.

**Кадры пустые или чёрные** — момент попал на затемнение между сценами. Возьми таймкод из `moments.txt` и вырежи кадр руками: `ffmpeg -ss 00:12:30 -i созвон.mp4 -frames:v 1 кадр.jpg`.

**Расшифровка идёт очень долго** — это процессор без ускорителя, возьми модель поменьше через `WHISPER_MODEL`.

**«модель не скачана»** — запусти разбор ещё раз и разреши скачивание, либо вручную: `vidnotes --download-model`.

## Чего не умеет

Не различает говорящих, не режет длинные записи на куски (транскрипт уходит целиком — часа на три речи запаса хватает) и не выбрасывает похожие кадры.
