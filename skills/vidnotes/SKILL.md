# vidnotes

Речь распознаётся локально (whisper.cpp), кадры режутся из видео, а какие моменты считать
ключевыми — решаешь ты по тексту расшифровки. Наружу отдаётся один markdown-файл: заголовок
на каждый момент, под ним кадр, в конце полный транскрипт.

Все команды ниже — `uv run`, он сам поднимает окружение с нужными пакетами при первом запуске.
Если `uv` не установлен, скажи пользователю поставить его: `brew install uv` (macOS) или
`winget install astral-sh.uv` (Windows), это разово.

Для краткости дальше `SCRIPT` = `"${CLAUDE_PLUGIN_ROOT}/vidnotes.py"`, а `RUN` =
`uv run --with pywhispercpp --with av`.

## 1. Модель

```bash
RUN SCRIPT --download-model
```

Если модели нет, качается около 550 МБ — предупреди об этом заранее и не запускай молча.
Если она уже на месте, команда просто скажет путь и завершится.

## 2. Расшифровка

```bash
RUN SCRIPT <видео> <язык> --transcribe-only
```

Язык — двухбуквенный код (`ru`, `en`, `de`) или `auto`. Бери язык из просьбы пользователя;
если он не сказал и по названию файла не ясно — спроси, на `auto` whisper иногда ошибается
на первых секундах и портит всю расшифровку.

Долгая часть: примерно вчетверо-впятеро быстрее самой записи, часовой созвон — минут
двенадцать. Предупреди пользователя, что это не мгновенно.

Команда напечатает путь к `transcript.srt` и сколько моментов имеет смысл взять.

## 3. Выбор моментов — твоя работа

Прочитай `transcript.srt` и выбери столько моментов, сколько посоветовала прошлая команда
(это примерно один на две минуты записи). Бери места, где что-то **решили, показали,
продемонстрировали или сменили тему**, и распределяй их по всей записи, а не по началу.

Запиши выбранное в файл `moments.txt` рядом с транскриптом, строго построчно:

```
00:03:22 | Базовая иерархия: пять уровней от филиала до соты
00:11:40 | Решили убрать ограничение на строки
```

Подписи — на языке записи, короткие, по делу. Никакой нумерации и преамбул: строки не
того вида просто игнорируются, а если подходящих не окажется, сборка честно откажется.

## 4. Сборка

```bash
RUN SCRIPT <видео> --moments <путь к moments.txt>
```

Скажи пользователю путь к получившемуся `<имя видео>_notes/<имя видео>_notes.md` и назови пару самых
содержательных моментов, чтобы он понял, что внутри.

## Мелочи, которые экономят время

- Результат ложится рядом с видео. Нужно в другое место — добавь `-o <папка>` к шагам 2 и 4,
  одинаковый в обоих.
- Конспект лежит внутри папки `<имя>_notes`, рядом с кадрами: переносить и отдавать надо
  папку целиком, отдельный `.md` останется без картинок.
- Если пользователь просит «только текст» — хватит шага 2, транскрипт уже готов в двух
  видах: `transcript.srt` с таймкодами и `transcript.txt` сплошняком.
- Если в записи почти нет речи, шаг 2 честно скажет об этом и остановится — не выдумывай
  моменты сам.
